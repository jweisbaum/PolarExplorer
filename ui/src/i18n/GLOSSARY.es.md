# Glosario de traducción: español

The Spanish words the interface and the help reference use for PolarExplorer's
own concepts, fixed so every area says the same thing. Companion to
`GLOSSARY.md` (its conventions apply). The audience is navigators, routers and
performance analysts: prefer the word a Spanish-speaking sailor, the Spanish
racing rules (RRV) or a routing program would use, not a dictionary's.

**Review status of every entry: machine-drafted, needs a native sailor.**
Entries marked **⚑** are the ones the translator was least sure of.

**Register.** Spanish addresses the reader as *usted* ("Haga clic", "su
proyecto"). Button and menu labels are infinitives ("Guardar", "Abrir…",
"Exportar…").

**Punctuation.** Opening ¿ and ¡; « » not used, plain quotes are fine. Keep `…`
where the English has it (it means "opens a dialog"). Keep every
`{placeholder}` exactly. Decimal and unit symbols are not localised.

**Never translated:** PolarExplorer, ORC, ORR, TWA, TWS, BSP, VMG, COG, SOG,
TWD, AWA, Expedition, Adrena, YellowBrick, Geovoile, Blue Water Tracks,
GeoJSON, CSV, GRIB, ERA5, WebGL2, file extensions (.wpsproj), unit symbols
(kn, m/s, km/h, m, ft, nm, km, GB, s, °).
