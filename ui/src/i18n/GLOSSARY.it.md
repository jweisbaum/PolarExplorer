# Glossario di traduzione — italiano

The words the Italian interface and help reference use for PolarExplorer's
concepts, in the spirit of `GLOSSARY.md`. **Review status of every entry:
machine-drafted, needs a native sailor.** Entries marked **⚑** are the ones
the translator was least sure of.

**Register.** Buttons and menu items use the short imperative macOS Italian
uses ("Salva", "Apri…", "Annulla", "Esporta…"). Tooltips that describe what a
control does use the third person ("Esclude i punti…", "Mostra…"). Instructions
to the reader use the impersonal infinitive ("Aprire un progetto per usarlo",
"Fare clic…"); questions are impersonal ("Salvare le modifiche?"). No *tu*, no
*Lei*.

**Punctuation.** Italian quotes « » without inner spaces; typographic
apostrophe ’. Decimal comma in prose and numbers shown as text (0,1 kn).
Keep `…` where the English has it and every `{placeholder}` exactly.

**Never translated:** PolarExplorer, ORC, ORR, TWA, TWS, BSP, VMG, COG, SOG,
TWD, AWA, Expedition, Adrena, YellowBrick, Geovoile, Blue Water Tracks,
GeoJSON, CSV, GRIB, ERA5, WebGL2, MMSI, file extensions (.wpsproj), unit
symbols (kn, m/s, km/h, m, ft, nm, km, MB, GB, s, °). Gender: *il* TWA, *il*
TWS, *la* BSP, *il* VMG, *il* COG, *lo* SOG.
