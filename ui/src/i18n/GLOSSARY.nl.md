# Translation glossary — Nederlands

The Dutch words the interface and the help reference use for PolarExplorer's
own concepts, in the spirit of `GLOSSARY.md`. The audience is navigators,
routers and performance analysts: prefer the word a Dutch or Flemish sailor, a
class rule or a routing program would use, not a dictionary's.

**Review status of every entry: machine-drafted, needs a native sailor.**
Entries marked **⚑** are the ones the translator was least sure of.

**Register.** The reader is addressed as *u* throughout. Button and menu
labels are infinitives ("Opslaan", "Openen…", "Exporteren").

**Punctuation.** Dutch uses no space before `: ; ? !` and writes quotes as
‘ ’ or “ ”. Keep `…` where the English has it (it means "opens a dialog"). Keep
every `{placeholder}` exactly as written. Compounds are written as one word
("polarsegment", "uitvoerraster"); with an abbreviation, a hyphen
("ORC-meetbrief", "TWA-bereik").

**Never translated:** PolarExplorer, ORC, ORR, TWA, TWS, BSP, VMG, COG, SOG,
TWD, AWA, Expedition, Adrena, YellowBrick, Geovoile, Blue Water Tracks,
GeoJSON, CSV, GRIB, ERA5, WebGL2, VPP, file extensions (.wpsproj), unit symbols
(kn, m/s, km/h, m, ft, nm, km, GB, s, °).

**Same in Dutch as in English** (kept on purpose, not left untranslated):
Help, Zoom, Filter, Project, Track(s), Tracker, Start, Finish, Export (noun),
Database, Heatmap, Overlay (only where shown as a technical term), 3D, 2D.
